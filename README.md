Question 3: Applications Using Data Structures and Algorithms
Real-world software systems rely on a combination of data organization and step-by-step procedures. Data structures store information while algorithms determine how the system manipulates it to deliver results quickly and accurately.
For example, search platforms depend on indexed structures and ranking algorithms to retrieve relevant information from massive datasets. Messaging applications use queues to maintain delivery order, while navigation services apply shortest-path algorithms on graph representations of roads. Word processors apply stack mechanisms to reverse user actions. 
The effectiveness of these systems comes from selecting structures that match the nature of the problem being solved.
| Data Structure | Application       | Algorithm Used | Reason             |
| -------------- | ----------------- | -------------- | ------------------ |
| Array          | Student records   | Linear Search  | Fast index access  |
| Stack          | Undo feature      | LIFO           | Tracks last action |
| Queue          | CPU Scheduling    | FIFO           | Fair processing    |
| Tree           | Database Indexing | Binary Search  | Fast searching     |
| Graph          | Google Maps       | Dijkstra       | Shortest path      |


Question 4: How Data Structures and Algorithms Work Within Systems
Within computing systems, data structures and algorithms form the core engine that drives functionality. Whenever a user performs an action, data must be stored, retrieved, updated and transmitted efficiently.
Operating systems maintain waiting tasks using queues, manage nested operations using stacks, and represent files through tree-like hierarchies. Database engines depend heavily on indexed trees and hashing to locate records in fractions of a second. Network infrastructure models connections as graphs so that routing algorithms can determine optimal paths.
Algorithms transform raw data into useful output by defining precise steps for searching, sorting, merging, comparing or optimizing. The closer the relationship between the chosen algorithm and structure, the better the overall system performance.
Therefore, understanding data structures and algorithms enables developers to build scalable, reliable and high-performance applications.
